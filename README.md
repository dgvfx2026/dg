# DG VFX Portfolio

Site portfólio profissional desenvolvido com HTML, CSS e JavaScript puro.

## Stack
- HTML5 semântico + SEO completo (Schema.org, Open Graph, Twitter Cards)
- CSS3 com variáveis customizadas — design dark minimal premium
- Vanilla JS — lazy loading, animações, modal de vídeo, cursor customizado
- Vídeos otimizados com FFmpeg NVENC (compressão ~92%)

## Estrutura

```
├── index.html          # Landing page completa
├── css/style.css       # Estilos + responsividade
├── js/main.js          # Animações, lazy loading, interações
├── assets/             # Thumbnails, favicon, foto, og-image
├── videos/             # Vídeos comprimidos (~55 MB total)
├── sitemap.xml
├── robots.txt
└── manifest.json
```

## Deploy no Vercel

1. Importe o repositório no [vercel.com](https://vercel.com)
2. Framework Preset: **Other** (site estático)
3. Build Command: deixar vazio
4. Output Directory: deixar vazio (raiz)
5. Deploy ✅
